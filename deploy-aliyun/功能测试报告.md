## 六、本次发现并修复的缺陷

### Java 格式化不生效（已修复）

**现象**：`POST /api/format` 传 `language=java` 时，单行代码原样返回，`changed=false`。

**原因**：原实现只按 `\n` 切行做缩进，不会把一行内的代码按 `{ } ;` 拆开。所以 `public class A{...}` 这种单行代码永远“已经是规范格式”。

**修复**：重写为字符级扫描器，能识别字符串、字符字面量、行注释、块注释、文本块，按 `{ } ;` 断行并统一 4 空格缩进，同时处理：
- `for(...)` 头部圆括号内的 `;` 不换行
- `} else {` / `} catch (...) {` / `} while (...);` 保持同一行
- 数组初始化 `{1,2,3}` 与 `new int[]{...}` 保持内联
- 已格式化的代码幂等（再格式化结果不变）

**验证**：12 个用例 + 12 项幂等检查全部通过，线上实测 `changed=true` 且输出正确。

## 七、已知限制（非缺陷）

1. **`tesseract.js` 已安装但前端未引用**：`src/` 里没有任何 OCR 调用，打包产物也不含 tesseract。`public/eng.traineddata`（5.1 MB）属于未被使用的遗留资源。图片实际是交给**千问视觉模型**（`qwen3-vl-plus`）识别，链路正常。

### 上线后发现并修复的缺陷：大文件模型分析返回 502

| 项 | 内容 |
| --- | --- |
| 现象 | 导入 `src/requests/sessions.py`（921 行 / 34KB）后，界面显示「规则 10 · 静态 4 · **模型 0**」，接口 `/api/analyze` 返回 502，耗时 49.9 秒 |
| 根因 | 系统提示词要求模型返回 `fixedCode`（修复后的**完整代码**）。921 行代码约 1.2 万 token，超过 `max_tokens=8000`，JSON 在中间被截断 → `extractJson` 解析失败 → 重试一次仍失败 |
| 修复 | ① 代码 > 400 行或 > 16KB 时改用精简提示词（`SYSTEM_PROMPT_NOFIX`）：只报问题，`fixedCode` 固定空字符串；② 响应带 `note`，界面顶部显示「这份文件有 921 行，本次只做问题定位，不生成整体重写版」；③ 「文件过长，暂无整份修复」按钮置灰，单条问题仍可用右侧「修复」；④ 错误文案从「模型输出不是合法 JSON」改成用户能看懂的话 |
| 验证 | 同一文件：52s 失败 → **10.0s 成功**，模型 12 条 + 规则 10 + 静态 4 = 19 条问题，平均分从虚高的 91 修正为 66 |
| 回归 | 修复后重跑接口 39 项、前端 27 项、文件导入 7 项、GitHub 端到端 13 项 + 边界 7 项，全部通过 |

## 十三、深色主题代码雨（v1.3，8 项边界检查全通过）

需求：在深色主题上加「黑客帝国」式字符飘落效果。首版预览偏暗（字符被天空底色、卡片遮罩、暗角三层压住），按反馈做了三档提亮，最终选定「2 档」落地。

### 实现

| 文件 | 改动 |
| --- | --- |
| `src/components/MatrixRain.tsx` | 新增。两层 canvas：底层静态画天空渐变 / 竖光丝 / 光点 / 暗角；上层字符用 `destination-out` 逐帧淡出形成拖尾，每帧只画新增字符 |
| `src/App.tsx` | 深色且开关打开时渲染 `<MatrixRain level={prefs.rainLevel} />`；`prefs` 增加 `rain`（默认开）与 `rainLevel`（默认 2） |
| `src/components/SettingsPanel.tsx` | 「外观」区新增「代码雨背景」开关 + 微弱 / 适中 / 明显三档 |
| `src/styles.css` | `.rain-host` 固定在 `z-index:-1`；`[data-rain="on"]` 时深色 token 换半透明（卡片 66%），编辑器与各类弹层保持不透明 |

挡不住阅读的三处保护：代码编辑器卡片、各类弹窗/抽屉强制不透明；`<768px` 与 `prefers-reduced-motion` 下完全不渲染；页面切到后台暂停 `requestAnimationFrame`。
