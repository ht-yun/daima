# 润色模板

把一段中文文字丢给码审，用同一套提示词做润色，保证每次输出结构一致。

## 用法一：拖文件

1. 把 `.docx` / `.txt` / `.md` 拖到桌面 **「码审 · 拖文件进来」** 图标上
2. 页面自动载入内容
3. 切到「对话」，把下面的提示词粘进去发出去

## 用法二：直接粘贴

```
你是中文技术文档编辑。请润色下面这段文字，要求：

1. 保持原意与事实不变，不新增原文没有的信息
2. 去掉口语化表达、重复和空话，长句改短
3. 术语前后统一，首次出现写成「中文（English）」
4. 输出三部分，按顺序：
   - 【润色后】全文，保留原有段落
   - 【改了什么】最多 5 条，每条一句话，说明为什么改
   - 【需要你确认】列出原文里含糊或可能失真之处，没有就写「无」

原文：
（在这里粘贴）
```

## 三种常见变体

| 场景 | 在提示词末尾追加 |
|---|---|
| 给评委看 | `语气克制，不吹牛，每个结论后面跟一句可验证的依据。` |
| 更短 | `整体压缩到原文的 60%，只保留结论和关键数据。` |
| 更正式 | `用书面语，避免「我们」「大家」，改为无主语句式。` |

## 输出长什么样

> **【润色后】**
> 码审把代码审查拆成三步：规则扫描、静态检查、模型分析。前两步在本地完成，耗时约 20 毫秒；第三步调用大模型，平均 5 秒返回。
>
> **【改了什么】**
> 1. 把「先跑一遍规则再交给 AI」改成三步表述，顺序更清楚
> 2. 补上具体耗时，原文只写「很快」
> 3. 删掉「非常非常」这类程度词
>
> **【需要你确认】**
> 原文说「毫秒级」，我按 20 毫秒写的，如果实际更慢请改。

## 小提示

- 文档太长时先分段，一次润色一节，比一次丢一万字效果好
- 润色不是改写事实：如果原文数据有错，模板会把它列在「需要你确认」里，不会替你编
